QA pipeline · YouTube demo One stop

One ticket, one line

Hand one Jira ticket to /qa-ticket and it runs from reading the ticket to close-out, stopping only once for case sign-off. Artifacts live in runs/{ticket}/; rerun /qa-ticket TICKET-xxx to resume after an interruption. Environment (dev / staging / prod) is an annotation, not a stage.

How cases are designed
  1. Test matrix10 techniques + self-check
  2. State machineonly with state transitions
  3. Prototypeonly for new pages
  4. BDD scenariosModified = diff only
  5. Independent review≥ 85, at most 4 rounds

★ Sign-off is the only step that needs your decision; every other stage is done by AI. Automation starts only after sign-off.

What you do

Only three things need you.

  1. 1 · Start

    Run /qa-ticket TICKET-xxx

    Context, risk and case design run on their own, with one progress line at the start and end of each stage.

  2. 2 · The only stop

    Open review.html, reply "approved"

    Matrix, state machine, prototype, acceptance list and BDD on one page. Ask for changes and it re-reviews before asking again.

  3. 3 · Wrap up

    Do the manual checks

    After sign-off it writes automation, runs tests and reviews code, then lists in progress.md the scenarios automation can't cover.

When it stops

Besides sign-off, only when it is truly stuck.

  • Case sign-off: the only fixed stop
  • Jira can't read the ticket, or it is too thin to design cases
  • Browser tooling unavailable or the target site unreachable
  • Suspected product bug: it asks before filing, never files on its own

Scenarios that can't be automated (NOT_FEASIBLE) or are outdated (TC_STALE) never stop the run; they are listed at close.

Before a release

Run once when a version's tickets are closed.

  • Pulls the version's tickets and open bugs by fixVersion, reads each ticket's progress.md verdict
  • Any open P0 bug → NO-GO; otherwise readiness ≥ 80 GO, 70–79 CONDITIONAL-GO
  • Writes releases/{version}.md: ticket status, post-deploy sanity checklist, sign-off table; a human always signs
