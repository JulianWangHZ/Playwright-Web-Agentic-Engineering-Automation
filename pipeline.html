GENERATOR AGENT

  • Converts approved test scenarios into automated test cases
  • Uses Playwright CLI / MCP to interact with and understand the application
  • Generates Playwright TypeScript test code
  • Creates reusable Page Objects, components & test helpers
  • Generates test data, configurations & supporting code
→
6

EXECUTION &
HEALER AGENT

⌁
  • Executes automated Playwright TypeScript tests
  • Collects and analyzes test failures, logs & test artifacts
  • Diagnoses application defects or automation issues
  • Performs self-healing for automation issues, such as locator updates
  • Re-runs affected tests to validate the fix
  • Creates a Jira bug only when a real product defect is confirmed
